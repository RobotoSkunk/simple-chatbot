## Notes for artists who came here for some reason
If you are an artist and came in here, you probably hate AI, so I'll need to
explain some stuff about this project... and congratulations, you know how to
use GitHub.

This project was built to run local AI models in mind by using downloaded AI
models with Ollama.

Local means the AI models are run in a local computer, meaning less energy
consumption, no water usage and no AI training, but more time to generate
responses and extra dumbness for AI responses.

Also, I don't have plans to add AI images generation to this because no, ew;
this also includes audios and videos. I may add support to let models to analyze
images because of pure fun, but no generate them.

And for the last point, ironically, no code has been generated with AI for this
project. As I said in the beginning of this file, this is a hobby project I
started because of a PewDiePie video.

TL;DR:
- This project is focused to local AI models.
- I won't add AI images generation.
- There's no AI training.
- There's no water consumption asides from the glass of water I drink.
- There's no huge energy consumption (unless your computer is an RGB circus).
- This is a hobby project.
- Stop using TikTok, Reels and YT Shorts if you skipped directly to the TL;DR
instead of reading the rest.
